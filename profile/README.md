# minlayer

We believe the following about doing good structured work with an agent:

1. No amount of intelligence will let a model read your mind
2. There will always be a need for a mix of determinism and non-determinism
3. Only a trivially large amount of text will get you exactly what you want in one shot
4. Getting things right consistently requires tight feedback loops at some level of abstraction
5. The abstraction ceiling increases with every model release, the need for feedback does not go away
